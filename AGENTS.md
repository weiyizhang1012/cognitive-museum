# Public repository working rules

This repository is the public system layer of Cognitive Museum. Treat the owner's real Vault, journals, attachments, ledgers, credentials and local backups as outside scope.

- Preserve the provenance and permission boundaries in the retrieval protocol.
- Never add real personal records or machine-specific absolute paths.
- All example records must be clearly synthetic.
- The coordinator and librarian files describe role modes; do not claim independent agent execution without evidence.
- Keep the combined handbook and project reference consistent with their source files.
- Report retrieval, delivery, file saves and synchronisation as separately verified operations.
- Do not add broad scanning, automatic writes, plugins or background services without a concrete user request.
