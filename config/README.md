# 项目配置

1. 在有权限的本地环境中，将 `${VAULT_ROOT}` 替换为你自己的 Vault 路径。
2. `${CAPTURE_BASKET}` 是可选的本地收件篮，仅在明确要求时读取；不需要它时可以保留未配置状态。
3. 在支持项目说明的 AI 环境中使用 `ChatGPT Project Instructions.md`，并添加 `project-reference/Museum Reference.md` 作为规则参考。
4. 参考文件只包含规则与模板。实际旧记录仍需要具有文件访问能力的后台按授权范围读取。
5. 使用者需要自行提供现有文件读取与聊天工具。此仓库提供工作规范与 Vault 骨架，跨聊天能力按运行环境实际确认。
