# Verification scope

## Original deployment evidence

The 2026-10-14 deployment in the original local environment:

- Updated and re-read 22 system files, including 14 librarian role prompts.
- Kept each of the 20 existing system files in a separate pre-deployment backup.
- Checked that the regenerated handbook contained the corresponding role text.
- Read an existing, non-life-record workflow test note and located its exact text and line numbers.
- Checked that the original test note, handoff ledger and project mirror were unchanged.
- Uploaded the project reference and compared a downloaded copy byte for byte.
- Saved and reopened the project instructions; checked the visible prefix and rendered final paragraph. The native accessibility reader returned only the first 10,000 UTF-8 bytes, so this is not represented as a byte-for-byte check of the entire saved instruction field.

No personal diary content is published as verification evidence.

## Public package checks

Before publication, the package is checked for local paths, personal identifiers, real record filenames, credentials, consistency between the independent role prompts and handbook, resolvable Obsidian wiki links, and accurate source locations in the synthetic example.

## Separate runtime acceptance checks

The following still need validation in the host environment where the workflow is used:

- A full, automatic cross-conversation dispatch and return round trip.
- Synchronisation to another device.
- A complete period review using the owner's authorised private records.
- Operation on another machine or AI host.

Configured roles are not reported as fourteen independently executed agents. Synthetic examples are not counted as additional live user-record tests.
